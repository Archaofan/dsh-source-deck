## 发布前追加实测

用户进一步要求自行完成检查、推送并发布，不再由用户测试。继续使用固定 RC 和本项目既有沙箱数据；安装临时诊断包，仅记录操作名、耗时和 DOM 反馈，不记录请求内容。最终包重新构建并移除诊断代码。

| 实际 Host 项目 | 样本 | p95 / 结果 |
|---|---:|---:|
| 6 / 24 / 200 条过滤反馈 | 各 30 次 | 33.7 / 33.2 / 76.1ms |
| 6 / 24 / 200 条对比选择反馈 | 各 30 次 | 30.2 / 29.7 / 28.8ms |
| 24 条列表判定反馈 / Host 确认 | 30 次 | 32.8 / 15.6ms |
| 24 / 200 条暖返回可操作候选 | 各 30 次 | 295 / 302ms 上界 |
| 200 条完整读取 | 32 次 | RPC p95 66ms；最大在途 1 |
| 可见终态 / 收藏 / 隐藏面板 | 各连续 60 秒 | 完整读取 2 / 0 / 0，活动读取各 30 |

反馈计时为捕获页面事件到插件首次 DOM 变动后的两个动画帧，是本机实验室近似值，**不是现场 INP 或精确像素绘制时间**。暖返回从控制端点击开始计时，包含控制调用开销；候选先使用保留视图恢复可操作状态，同时后台请求新鲜数据，不把它写成全新数据加载或冷启动。完整分钟只截取每次启动后前 60,000ms；实际观察分别持续 110,001 / 71,387 / 72,066ms。指标摘要见 [Host 数据](../research/probes/2026-10-19-host-acceptance-summary.json)。

内存矩阵另测 6/24/200 条 × 1/100/1,000 主题，每格 30 次：最大规模读取 p95 2.575ms、分组与事实格式化 p95 0.539ms。它不包含磁盘/RPC/React，也**不是实际 Host 的历史规模矩阵**。可复跑[探针](../research/probes/2026-10-19-experience-acceptance.mjs)，原始汇总见 [JSON](../research/probes/2026-10-19-experience-acceptance.json)。现有证据不支持追加存储重构或虚拟列表。

五条单人任务走查通过：六选二插入引用并续写、中文编辑换行/Escape/重新展开保稿、候选和收藏独立查询、0/6 清除恢复、两项对比返回当前按钮焦点。正文 `QA 中文草稿：筛选两项后继续撰写，不发送。` 与 `SourceDeck · 2` 同时保留，未发送。它是代理执行的场景走查，**不是 3–5 名真人研究**；普通中文文本输入不等于真实 OS IME composition 验收。

真实附件上传两次被浏览器权限审核拒绝；第二次发生在用户明确授权仅含验收文字的 `qa-attachment.txt` 后。未通过其他接口绕过该限制，附件组合只保留自动协议回归结果，不能标记实际上传通过。

- 上表代表性动作满足本机 100ms 反馈 / 500ms 暖返回预算；不扩大为所有动作、所有机器、全新加载、图片完成或 INP 承诺。真实 1/100/1,000 主题 Host 矩阵和冷启动未测。
