## 沙箱升级（先于产品）

旧基线 rc.1 归档 `sandbox/dsh-desktop/archives/rc-0.2.2-rc.1-20261112T135229Z/`（`git archive` 源码 tar + home/electron-user-data/appdata/localappdata/tmp/logs/scripts/baseline/status；**不含** `upstream/node_modules` 与构建产物，回滚用 checkout + `pnpm install --frozen-lockfile`）。`baseline.json` 改为 rc.2，`productionVersion` 保留 `0.2.2-rc.1`，`sandboxRelation=ahead-of-production` 并记录用户批准。

```powershell

pnpm install --frozen-lockfile --config.confirmModulesPurge=false              # 首次挂起；CI=true 重跑 3m34s exit 0
```

第一次 `pnpm install` 在供应链校验后无进展（缺非交互确认）；`CI=true` 重跑完成，未关闭 frozen lockfile 或校验策略。

**沙箱脚本适配**：rc.2 的 `runDesktopCli` 只接受 `supportDir`；`scripts/desktop-cli.mjs` 改为传 `targets/win-x64/runtime` 并检查其 pnpm。未改上游源码。

## 产品改动

- `package.json`：`0.4.1 → 0.4.3`（0.4.2 为同日中间版本）；六个 DSH peer 与全部官方 Client 类型 devDependencies 精确 `0.2.2-rc.2`；Cordis `4.1.0`。
- `zod 4.4.3 → 4.6.6`：`dsh-typert-protocol@0.2.2-rc.2` 的硬要求；旧类型缺 `validate`/`validateAsync`，`src/remote-info.ts` 报 5 处 `TS2322`。
- **`src/research-runtime.ts`（唯一代码改动）**：rc.2 把 `subagents.startActivation` 的参数从 `request: { parent, prompt }` 拍平为顶层 `parent` / `prompt`。0.4.2 仍传嵌套结构，宿主读 `spec.parent.id` 得到 `undefined`，研究回合 **8 ms 内**以 `Cannot read properties of undefined (reading 'id')` 失败。0.4.3 改为扁平传参。
- 新增 `tests/research-runtime.test.ts` 锁定该形状（先红后绿）：断言 `parent` 在顶层、`request` 不存在、`prompt` 为文本块数组。
- `pnpm-workspace.yaml`：`minimumReleaseAgeExclude` 更新到 rc.2 全量并加入 `zod@4.6.6`。

## 实际 Host 验收（含真实模型）

Host 为 `0.2.2-rc.2-ddac967`。经用户授权，把生产 `DEEPSEEK_API_KEY` 单独写入沙箱隔离 `.credentials.yaml`；验收后移除并恢复原文件（沙箱凭据恢复为 161 bytes，不再含该 key）。

- **无密钥 UI**：入口/tab、旧数据重放、手动添加、保留+撤销、引用 chip、设置 section、保存策略、原生 confirm 清除数据均通过；控制台只有 Electron 既存 CSP 警告。
- **真实聊天**：发送「只回复 OK」，2 秒回复 `OK`，16.4K tok。
- **真实后台研究**：经资料台「新搜索」发起，约 40 秒完成，返回 2 个真实 GitHub 来源（`tyleruploads/mdez`、`retext-project/retext`），状态「已完成」。
- **引用回对话**：保留 MDEZ++，插入 `SourceDeck · 1` chip 并发送「只根据引用里已有的资料，回复你看到的来源名称。」；模型只依据引用 JSON 回答，指出 `sources` 长度为 1 且来源是 `tyleruploads/mdez`，证明引用内容真实进入模型上下文。

证据：`sandbox/dsh-desktop/test-workspaces/dsh-source-deck/rc2-research.png`、`rc2-reference-send.png`，以及 `cdp-*-rc2.mjs` 探针。

## 0.4.2 的失败与处置

0.4.2（同日早先发布）只改了 peer 与 `zod`，未跟进 `startActivation` 拍平。它通过 UI 验收，但任何研究回合都会立即失败；释放后 0 下载即被发现。处置：不删除 Release/tag（避免破坏性远程操作），发布 0.4.3 并在 0.4.2 的 Release 正文与 README 标注 **superseded，请勿使用**。
