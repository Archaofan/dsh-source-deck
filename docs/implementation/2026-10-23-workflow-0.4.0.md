## 实际变化

- 候选与收藏统一搜索已有标题、URL、说明、摘录、语言、许可证和 topics；候选另含筛选原因。空格分隔多个词时要求全部匹配，不发起远程搜索。
- 默认保留原顺序；可在每轮内按 stars、最近代码 push 或名称排序。未知数值/日期排后，0 stars 有效，同值稳定；收藏单独记住查询及排序。
- 对比直接显示最多四个可移除名称，支持清空、打开；比较列按选择顺序排列。未选卡片在满额时就地说明上限。键盘移除后移到相邻项，末项回退到结果说明；异步回调不抢走后来移开的焦点。
- 最新成功确认的本地显式判定可撤销，恢复之前的 verdict 和 reason，原因自动保存不占独立撤销历史。撤销使用原写入队列，期间锁定当前主题编辑及引用；失败可重试。后续同项编辑、观测到冲突、切主题、只读或清除后不提供旧撤销。它不是跨窗口原子撤销，也不跨重启保存。
- note 标为「研究判断」。研究提示要求适用点及关键限制/待核验点，description 留作简介；license/archived 只在查到时填写。用户指定数量/名单优先于默认候选数，不能扩展关联项目凑数。不新增模型调用、工具、自动查证服务或数据表。
- 首次打开当前资料集时先解析实际 setId，统一输入框入口与历史卡片的草稿键。旧 active 草稿仅在同会话、规范草稿尚不存在时复制，原记录保留；不同入口返回同主题不再丢查询、排序或对比选择。首次未定向打开会多一次按 ID 读取，随后复用已记住的目标，不改变静置调度。

保持精确 DSH `0.2.1-rc.2` / Cordis `4.0.5`；没有新增依赖、lockfile 图变化、上游修改或生产配置变化。

## 模型样本的实际边界

进行了两轮正常受管研究测试。首轮请求限定 Zotero Connector 与 Obsidian Web Clipper，却返回六个来源；确认原提示默认数量与用户限定冲突后修正。相同需求再测返回指定的两个官方仓库，note 含用途和限制，附 metadata 来源 URL。**这只证明该样本遵循了数量/对象要求，不证明普遍准确率或事实都已核验。** 星数、许可证、限制与查询时间未逐项独立审计，模型生成的查询时间尤其不能自动视为 Host 测量值。

另外，为使三个合成 QA 会话出现在列表，曾通过 `session/prompt` 发送 `/deck`；该 API 把它当普通模型文本，而非客户端斜杠指令，实际触发了三个父会话模型请求，随后只取消这三个 QA 会话。它们不计入研究质量样本。之后的界面操作通过现有入口进行，未从生产导入账号或配置。

原生 Electron 125% 缩放、真实中文 IME、真实附件组合、屏幕阅读器播报及真人观察仍未完整覆盖；未重跑完整一分钟/历史规模性能矩阵，不宣称提速比例。
