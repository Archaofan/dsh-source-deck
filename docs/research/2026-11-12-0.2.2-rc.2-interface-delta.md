- tag `dsh-v0.2.2-rc.2`，commit `ddac96760b6edf8fa0fe17cbdcf0b512f4c12b2c`；GitHub Release 发布于 `2026-11-11T11:33:06Z`，npm 发布 `2026-11-12T02:16:12Z`。

## 唯一需要跟进的依赖：zod 4.6.6

`@deepseek-ai/dsh-typert-protocol@0.2.2-rc.2` 的 `dependencies` 精确声明 `zod: 4.6.6`。SourceDeck 原来锁 `zod@4.4.3`，`tsc` 在 `src/remote-info.ts` 报 5 处：

```text
error TS2322: Type '{ mode: "strict"; typeSymbol: string; create: () => z.ZodString; … }'
is not assignable to type 'TypertRemoteCodecSpec'.
  The types returned by 'create()' are incompatible …
  Type 'ZodString' is missing the following properties from type
  'ZodType<unknown, unknown, $ZodTypeInternals<unknown, unknown>>': validate, validateAsync
```

把 `zod` 升到 `4.6.6`（并在 `pnpm-workspace.yaml` 的 `minimumReleaseAgeExclude` 中列出）后 `tsc` 退出 0。这是本轮唯一的产品依赖变化；没有新增依赖，也没有改业务代码。
