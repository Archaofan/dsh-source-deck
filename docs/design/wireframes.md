# SourceDeck 界面草图（v1，待审阅）

日期：2026-10-17。配套 [2026-10-17-solution-design.md](2026-10-17-solution-design.md)。ASCII 线框仅表达布局与信息架构，不代表最终视觉；最终视觉遵循 Desktop 的 `--dsw-*` token 与 CSS Modules 规范。

## 1. 右栏「资料台」tab（主面板）

挂点：`ctx.sidebarRightTabs.register` + keyed `sidebar.right.pane.tab`（key=`sourcedeck`）。scope=session，只显示当前会话的活跃候选集。

├─────────────────────────────────────┤
│ [当前候选集 #set-3f2a · 来自 Agent]   │  ← sets 记录：origin/createdAt
│ ┌─────────────────────────────────┐ │
│ │ ▸ 待处理 (3)                    │ │  ← 分组：verdict=pending
│ │  ▸ 1 《DSH 插件机制概述》         │ │

## 2. 对话流候选卡片

挂点：`ConversationNodeDefinition`（kind=`source-deck/set`）+ keyed `conversation.chat.node`。数据从 log-only 事件 `source-deck/set-opened` 折叠；卡片在会话中持久，重启后回放重建。

```
┌─ 对话流 ─────────────────────────────────────────┐
│ (用户) 帮我找 DSH 插件 UI 扩展的资料               │
│ (助手) 好的，我调用资料收集工具……                  │
│ ┌─ 工具调用 deck_submit_sources ───────────────┐ │
│ │ ✓ 已收入 8 条候选                              │ │  ← output.render 文本
│ └──────────────────────────────────────────────┘ │
│ ┌─ 📚 候选资料集 · 8 条 ───────────────────────┐ │  ← SourceDeck 业务卡片
│ │ 1 《DSH 插件机制概述》  dsh-docs.example       │ │
│ │     摘要：工具注册与 slot……          [保留][排除]│ │
│ │ 2 《Cordis 生命周期》    github.com/...        │ │
│ │     摘要：effect 与 dispose……       [保留][排除]│ │
│ │ 3 《Slots 参考》         ...                   │ │
│ │     ...（折叠，展开看全部 8 条）                │ │
│ │ ─────────────────────────────────────────────  │ │
│ │ 保留 0 · 排除 0 · 待处理 8    [在资料台打开 ▸] │ │  ← 打开右栏 tab
│ └──────────────────────────────────────────────┘ │
└──────────────────────────────────────────────────┘
```

用户勾选后（卡片按钮与资料台是同一份 verdict，双向同步）：

```
│ ┌─ 📚 候选资料集 · 8 条 ───────────────────────┐ │
│ │ 1 《DSH 插件机制概述》              ✓ 保留    │ │
│ │ 2 《Cordis 生命周期》                ✗ 排除    │ │
│ │ 3 《Slots 参考》                     ✓ 保留    │ │
│ │ ─────────────────────────────────────────────  │ │
│ │ 保留 3 · 排除 2 · 待处理 3     [提交给 Agent] │ │
│ └──────────────────────────────────────────────┘ │
```

## 3. 输入区入口与提交后

入口：`conversation.input.right`（list，additive）—— 模型选择器与发送按钮旁的「资料台」按钮，点击 `ctx.sidebarRight.openTab('sourcedeck')`。

```
┌─ composer ─────────────────────────────────────────────┐
│ [📎] [输入框：问点什么，或 @ 引用文件……]        [📚 资料台] [发送] │
│        ↑ conversation.input.left   ↑ input.right 按钮      │
└───────────────────────────────────────────────────────┘
```

提交后（queue 模式，Agent 空闲时开新轮次；steer 模式插入运行中轮次的下一步）：

```
│ (用户 · SourceDeck 提交)                                │
│ 用户已筛选资料集（共 8 条候选）：                        │
│ 保留 3 条：1)《DSH 插件机制概述》<url> 2)……              │
│ 排除 5 条：6)《无关：安装指南》（理由：广告）……           │
│ 请基于保留资料继续。                                     │
```

忙碌时资料台顶部显示运行状态条，提交按钮文案变为「插入到下一条（steer）」并附说明。

## 5. 主流程状态图

```
                ┌──────────────┐
                │ 空闲         │
                └──────┬───────┘
        Agent 调用工具 / 用户添加资料
                       ▼
              ┌────────────────┐   decide（保留/排除，不唤醒）
              │ 候选集打开      │◄──────────────┐
              │ (set-opened)   │               │
              └──────┬─────────┘               │
                     │ 提交给 Agent             │
                     ▼                          │
        ┌─────────────────────────┐             │
        │ commitSelection         │             │
        │  写 selections + emit   │             │
        └───────────┬─────────────┘             │
                    ▼                           │
     ┌───────────────────────────────┐          │
     │ session.prompt                │          │
     │  running → steer（下一步边界）  │          │
     │  idle    → queue（新轮次）     │          │
     └──────────────┬────────────────┘          │
                    ▼                           │
        ┌───────────────────────┐               │
        │ Agent 看到选择摘要     │               │
        │ 继续阅读/比较/排除     │               │
        └───────────┬───────────┘               │
                    │ 可再次 decide             │
                    └───────────────────────────┘

  重启/回放：候选卡片 ← log-only 事件折叠；资料台 ← 域存储
  多会话：sets/candidates/selections/session_active 全部带 sessionId
```
