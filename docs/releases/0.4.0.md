# SourceDeck 0.4.0 — 减少资料筛选与引用的操作阻力

在已有研究、筛选和引用流程中，更快找到候选、调整对比名单，并恢复误判。0.4.0 按预发行交付，稳定版入口保留 0.3.0。

- **组合搜索与排序**：标题、URL、说明、筛选原因及已有语言、许可证、标签可一起搜索；空格分词同时匹配。候选按轮次稳定排序，未知值排后；候选与收藏分别保留查询和排序。
- **可见对比名单**：直接查看、逐项移除或清空所选来源，最多四项，比较列跟随选择顺序；窄栏继续按维度阅读。
- **撤销最近判定**：恢复最近成功保存的本地判定与原原因；切主题、后续同项编辑或发现冲突后失效，不提供跨窗口原子撤销。
- **研究判断与入口接续**：新研究提示要求适用点、关键待核验点，并遵循明确名单/数量；同主题在输入框与历史卡片入口之间保留查询、排序、对比和草稿。模型输出仍需核验。

精确支持 **DSH Desktop 0.2.1-rc.2 / Cordis 4.0.5**。没有新增依赖、数据表或支持基线变化。引用等待筛选写入完成，保留输入框草稿且不自动发送。

验证：94/94 自动测试、6/6 实际组件交互、构建及官方沙箱安装字节核对通过。固定 RC Host 覆盖中英深浅、四种面板宽度和 6/24/200 项；两轮实际研究中的数量约束问题已修正，第二轮只返回指定两项，不代表普遍事实准确率。原生缩放、真实 IME/附件组合、屏幕阅读器播报及真人观察尚未完整覆盖，未重跑完整性能矩阵。生产未操作。

安装：下载本 Release 的 `dsh-source-deck-0.4.0.tgz`，在 Desktop 插件管理页本地安装，按提示重启。市场目录目前仍指向 0.3.3，不应作为本版本安装入口。
