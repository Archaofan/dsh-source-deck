# SourceDeck 0.4.3 — 适配 DSH 0.2.2-rc.2（正式发布）

本版本为**正式 Release（非预发行）**，GitHub `Latest` 指向 `v0.4.3`。

0.4.3 让 SourceDeck 真正跑通 DSH Desktop **0.2.2-rc.2 / Cordis 4.1.0**。它是 0.4.2 的修复版：0.4.2 能加载，但启动研究回合会立刻失败。

- **接口破坏**：rc.2 把 `subagents.startActivation` 的参数从 `request: { parent, prompt }` 拍平为顶层 `parent` / `prompt`。0.4.2 仍传旧嵌套结构，宿主在 `spec.parent.id` 处得到 `undefined`，研究回合以 `Cannot read properties of undefined (reading 'id')` 失败。0.4.3 改为扁平传参，并新增回归测试锁定该形状。
- **依赖跟进**：`@deepseek-ai/dsh-typert-protocol@0.2.2-rc.2` 要求 `zod@4.6.6`；`zod` 由 `4.4.3` 升到 `4.6.6`。
- **无功能变更**：八表、研究提示、筛选/对比/引用协议和 UI 均未改动，旧数据保持可读。

精确支持 **DSH Desktop 0.2.2-rc.2 / Cordis 4.1.0**。0.4.2 是同一基线的失败版本，请勿使用；0.4.1 只支持 `0.2.2-rc.1`，0.4.0 只支持 `0.2.1-rc.2`。

验证：**95/95** 自动测试、tsdown+tsc 构建、官方沙箱 `Install-Plugin.ps1` 安装（退出 0、无兼容拒绝或版本豁免）与安装字节核对通过。实际 Host（`0.2.2-rc.2-ddac967`）验证了资料台入口/tab、手动添加、保留与撤销、引用 chip、设置 section、保存策略与清除数据；经用户授权复用生产 `DEEPSEEK_API_KEY`（仅写入沙箱隔离凭据，验收后移除并恢复原文件）完成真实模型链路：聊天回复 `OK`；后台研究约 40 秒返回 2 个真实 GitHub 来源（`tyleruploads/mdez`、`retext-project/retext`）并「已完成」；保留 MDEZ++ 后插入引用并发送，模型只依据引用 JSON 报出来源名称，并指出 `sources` 长度为 1。单样本不代表普遍研究质量或事实准确率。

限制：PTC 父预设分支未单独切换复验；Electron 原生 125% 缩放、真实中文 IME、附件组合、屏幕阅读器、真人观察和完整四宽四主题/性能矩阵未重跑。生产 Desktop 仍是 `0.2.2-rc.1`，未安装本版本。

安装：下载本 Release 的 `dsh-source-deck-0.4.3.tgz`，在 Desktop 插件管理页本地安装，按提示重启。市场目录当前仍指向 0.4.1，不应作为本版本安装入口。

English: SourceDeck 0.4.3 makes the plugin actually work on DSH Desktop **0.2.2-rc.2 / Cordis 4.1.0**. It fixes 0.4.2, which loaded but failed every research round at startup.

rc.2 flattens `subagents.startActivation` from `request: { parent, prompt }` to top-level `parent` / `prompt`; 0.4.2 still sent the nested form, so the host read `spec.parent.id` on `undefined` and the round failed with `Cannot read properties of undefined (reading 'id')`. 0.4.3 passes the flat spec and adds a regression test. The other required follow-up is `zod@4.6.6` for `dsh-typert-protocol@0.2.2-rc.2`. Features, data tables, research prompts and UI are unchanged.

Exact support is DSH `0.2.2-rc.2` / Cordis `4.1.0`. Do not use 0.4.2; 0.4.1 only supports `0.2.2-rc.1` and 0.4.0 only `0.2.1-rc.2`.

Verification: **95/95** tests, tsdown+tsc build, official sandbox installation (exit 0, no compatibility rejection or exemption) and installed-byte checks passed. The actual Host (`0.2.2-rc.2-ddac967`) exercised the deck entry/tab, manual add, keep/undo, reference chips, settings, policy save and data clearing. With the user's authorization to reuse the production `DEEPSEEK_API_KEY` (isolated sandbox credential only, removed and restored afterwards), real model calls passed: a chat reply `OK`; a ~40-second research round returning two real GitHub sources (`tyleruploads/mdez`, `retext-project/retext`) with status completed; and a kept MDEZ++ reference the model answered from correctly after sending, noting `sources` length 1. One sample does not prove general research quality or fact accuracy.

Limitations: the PTC-parent preset path was not separately retested; native zoom, real IME/attachment combinations, screen-reader speech, human observation and the full matrix remain incomplete. Production Desktop stays on `0.2.2-rc.1` and this version is not installed there.

Install the attached `dsh-source-deck-0.4.3.tgz` through Desktop's plugin manager. The market catalog still points to 0.4.1 until the update PR merges. The package is **189287 bytes / 53 files**; its artifacts and both READMEs match the installed bytes (per-file SHA256 in the [implementation and acceptance record](https://github.com/Archaofan/dsh-source-deck/blob/main/docs/implementation/2026-11-12-0.2.2-rc.2-adaptation.md)).
