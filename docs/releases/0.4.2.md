# SourceDeck 0.4.2 — 适配 DSH 0.2.2-rc.2

0.4.2 将 SourceDeck 适配到 DSH Desktop **0.2.2-rc.2 / Cordis 4.1.0**。功能与界面不变，稳定版入口继续保留 0.3.0。

- **基线适配**：四个 DSH peer、官方 Client 类型包与 Cordis 精确升级到 `0.2.2-rc.2`。
- **没有插件代码改动**：0.2.2-rc.2 的插件契约差异都是新增的可选字段（`insertQuote` 的摘要参数、`consumeOlder`、`conversation.chat.markdown.fence` 槽位、`enter.allowEmpty`），SourceDeck 均未使用。
- **依赖跟进**：`@deepseek-ai/dsh-typert-protocol@0.2.2-rc.2` 要求 `zod@4.6.6`（新增 `validate`/`validateAsync` 类型）；`zod` 由 `4.4.3` 升到 `4.6.6`。
- **无功能变更**：八表、研究提示、筛选/对比/引用协议和 UI 均未改动，旧数据保持可读。

精确支持 **DSH Desktop 0.2.2-rc.2 / Cordis 4.1.0**。0.4.1 只支持 `0.2.2-rc.1`，0.4.0 只支持 `0.2.1-rc.2`，都不能在 0.2.2-rc.2 环境加载。

验证：**94/94** 自动测试、tsdown+tsc 构建、官方沙箱 `Install-Plugin.ps1` 安装（退出 0、无兼容拒绝或版本豁免）和安装字节核对通过。实际 Host（`0.2.2-rc.2-ddac967`）验证了资料台入口/tab、手动添加、保留与撤销、引用 chip、设置 section、保存策略与清除数据（原生确认框）。**本轮没有做真实模型研究**：复用生产 API key 需要用户单独授权，未授权则只完成无密钥的 UI 验收。

限制：PTC 父预设分支未单独切换复验；Electron 原生 125% 缩放、真实中文 IME、附件组合、屏幕阅读器、真人观察和完整四宽四主题/性能矩阵未重跑。生产 Desktop 仍是 `0.2.2-rc.1`，未安装本版本。

安装：下载本 Release 的 `dsh-source-deck-0.4.2.tgz`，在 Desktop 插件管理页本地安装，按提示重启。市场目录当前仍指向 0.4.1，不应作为本版本安装入口；目录更新 PR 合并后条目才会跟进。
