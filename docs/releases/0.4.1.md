# SourceDeck 0.4.1 — 适配 DSH 0.2.2-rc.1

0.4.1 将 SourceDeck 适配到 DSH Desktop **0.2.2-rc.1 / Cordis 4.1.0**。功能与界面不变，稳定版入口继续保留 0.3.0。

- **基线适配**：四个 DSH peer、官方 Client 类型包与 Cordis 精确升级；新增 `@deepseek-ai/dsh-tool-executor-native` 和 `@deepseek-ai/dsh-tools`。
- **工具呈现修复**：0.2.2 删除了 `tools.presentAs()`，研究 worker 改为在自己的 scope 挂载官方 native executor；原有工具限制与守卫不变，研究 worker 仍只能使用 `web_search`、`web_fetch`、`deck_submit_sources`。
- **无功能变更**：八表、研究提示、筛选/对比/引用协议和 UI 均未改动，旧数据保持可读。

精确支持 **DSH Desktop 0.2.2-rc.1 / Cordis 4.1.0**。已发布的 0.4.0 只支持 `0.2.1-rc.2`，不能在 0.2.2-rc.1 环境加载。

验证：**94/94** 自动测试、tsdown+tsc 构建、官方沙箱 `Install-Plugin.ps1` 安装和安装字节核对通过。实际 Host 验证了资料台入口/tab、手动添加、对话卡片、保留判定、引用 chip、设置 section 与清空数据。按用户指示使用与生产相同的 DeepSeek API（仅复制 `DEEPSEEK_API_KEY` 到沙箱隔离凭据）完成真实模型验收：聊天回复 `OK`；后台研究约 30 秒返回 `KDE/ghostwriter`、`pbek/QOwnNotes` 两个真实 GitHub 来源并「已完成」；保留 Ghostwriter、插入引用并发送后，模型正确读取引用 JSON。单样本通过不代表普遍研究质量或事实准确率。

限制：PTC 父预设分支未单独切换复验；Electron 原生 125% 缩放、真实中文 IME、附件组合、屏幕阅读器、真人观察和完整四宽四主题/性能矩阵未重跑。生产未操作。

安装：下载本 Release 的 `dsh-source-deck-0.4.1.tgz`，在 Desktop 插件管理页本地安装，按提示重启。市场目录目前仍指向 0.3.3，不应作为本版本安装入口。

English: SourceDeck 0.4.1 adapts the plugin to DSH Desktop **0.2.2-rc.1 / Cordis 4.1.0**. Features and UI are unchanged; stable 0.3.0 remains available.

The only interface-level change replaces the removed `tools.presentAs()` with the official native tool executor mounted in each research worker's own scope. Tool restrictions and guards are unchanged, so workers still see only `web_search`, `web_fetch`, and `deck_submit_sources`. Exact peers are DSH `0.2.2-rc.1`, Cordis `4.1.0`, `@deepseek-ai/dsh-tool-executor-native` `0.2.2-rc.1`, and `@deepseek-ai/dsh-tools` `0.2.2-rc.1`; the published 0.4.0 only supports `0.2.1-rc.2`.

Verification: **94/94** tests, tsdown+tsc build, official sandbox installation and installed-byte checks passed. The actual Host exercised the deck entry/tab, manual add, conversation cards, keep decisions, reference chips, settings section and data clearing. With the user's same-API instruction (only `DEEPSEEK_API_KEY` copied into the sandbox's isolated credential store), real model acceptance passed: a chat reply `OK`; a ~30-second research round returning two real GitHub sources (`KDE/ghostwriter`, `pbek/QOwnNotes`) with status completed; and a kept Ghostwriter reference that the model read correctly after sending. One sample does not prove general research quality or fact accuracy.

Limitations: the PTC-parent preset path was not separately retested; native zoom, real IME/attachment combinations, screen-reader speech, human observation and the full four-width/four-theme performance matrix remain incomplete. Production was untouched.

Install the attached `dsh-source-deck-0.4.1.tgz` through Desktop's plugin manager; the market catalog still points to 0.3.3. The package is **188322 bytes / 53 files**; its `lib/index.js`, `lib/client.js`, `package.json` and both READMEs match the installed bytes. SHA256 is above.
